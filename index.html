FlavourSuite AI in development

Make your WordPress site agent-ready. A Model Context Protocol (MCP) server built on the WordPress core Abilities API, so Claude, Cursor, ChatGPT and other MCP clients can work with your site through safe, structured tools.

  • Off by default — the endpoint doesn't exist until you enable it
  • Permission-checked — agents act as a real WordPress user, never anonymously
  • Read-only first — per-tool switches; anything that writes is opt-in
  • Audited — see who called which tool, when, and whether it succeeded
  • Private — no API keys, no outbound requests; your data stays on your site
  • Plays well with others — WooCommerce and FluentCRM tools appear automatically

Why "agent-ready" matters

Agents that scrape pages get things wrong and see things they shouldn't. The right way is structured: named tools with schemas, WordPress capabilities enforced on every call, and a human-readable trail of everything that happened. That's what we build — on the same open standards WordPress itself is adopting.
